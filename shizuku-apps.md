# Awesome Shizuku Apps

Apps that work with Shizuku (ADB-level access without root).

## System Control

| App | Description | GitHub |
|-----|-------------|--------|
| **App Manager** | Full app control, permissions, components, storage | [GitHub](https://github.com/MuntashirAkon/AppManager) |
| **Activity Launcher** | Launch any activity, broadcast receiver, service | [GitHub](https://github.com/burlaps/ActivityLauncher) |
| **Blocker** | Disable apps per user without uninstall | [GitHub](https://github.com/blokada/blokada) |
| **Shelter** | Create isolated work profile, auto-freeze apps | [GitHub](https://github.com/evilsocket/shelter) |
| **Storage Isolation** | Sandbox file access per app | [GitHub](https://github.com/zacharee/StorageIsolation) |

## Developer Tools

| App | Description |
|-----|-------------|
| **ClassyShark** | APK analyzer and bytecode viewer |
| **Logcat** | Advanced logcat reader with filtering |
| **NetGuard** | Per-app firewall without root |
| **PCAPdroid** | Network traffic capture and analysis |

## File Management

| App | Description |
|-----|-------------|
| **MiXplorer** | Advanced file manager with plugins |
| **Material Files** | Clean open-source file explorer |

## Installation

1. Install **Shizuku** from GitHub: https://github.com/RikkaApps/Shizuku
2. Start Shizuku (via ADB or Wireless Debugging)
3. Install apps from F-Droid or Play Store
4. Grant Shizuku permission in each app's settings

**Tip:** Combine with LSPosed for even more power.
