# Recommended Shizuku Modules

Curated list of well-maintained modules for daily use.

## Must-Have
- **Shizuku** — Core service https://shizuku.rikka.app
- **App Manager** — Full app control, permissions, components

## Privacy & Security
- **Applock** — Password-protect individual apps
- **Privacy Indicator** — See which apps accessed camera/mic/location

## System Tweaks
- **TextDroid** — Change system text size per app
- **NavBar Apps** — Add app shortcuts to navigation bar

**Note:** Install from F-Droid or GitHub releases.
